# design/ — early vision docs (March 2026)

The founding philosophy of LucentForge: emergent NPC autonomy, the player as one more agent,
persistence, and the long-term port strategy. Still worth reading for the *why*.

**Authority:** where these docs differ from `docs/bible/`, the bible wins. The bible is the
§-numbered design authority that code and requirements cite. These files are context, not spec.
