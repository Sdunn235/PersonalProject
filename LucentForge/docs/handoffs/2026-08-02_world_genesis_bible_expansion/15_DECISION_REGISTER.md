# Open Decision Register

These questions should not be answered by Claude alone.

## Planet scale

- Is the master map 2048x1024, 1024x512, or another projection?
- What is the planet circumference?
- What physical size does one tile represent?
- What physical span does an 18x18 Panel represent?
- How many Panels may one macrocell index?

## Tectonics

- Are movement arrows absolute or relative?
- Is the Deep Ocean Plate one deforming plate or two plates?
- Which Central Plate boundaries are continent-continent versus subduction?
- Which plates are continental, oceanic, or mixed?
- Are polar plates true plates or map-edge convenience regions?

## Canon

- Is the approaching-supercontinent state final canon?
- Is the central world peak objective geology, Grace-modified geology, or both?
- Are Greaterlands/Lessorland final names or working labels?
- Are Northern/Southern Archipelago identities accepted?

## Genesis

- Does the canonical world need to be reproducible exactly from Genesis?
- Which handcrafted layers are locked?
- Which layers may Genesis revise?
- Is Python the initial implementation language?
- Which data format becomes the first artifact contract?

## Workflow

- Which map file is the authoritative layered master?
- Which asset versions are retained in Git?
- Should large PSD files use Git LFS?
