# Story / Lore — Memory Log

Append-only history of narrative/lore this department has written. Newest at the top.

**Entry format:**
```
## YYYY-MM-DD — <character / lore element>
- **Intent:** one line.
- **Content:** the core of the narrative/character in 1–3 lines.
- **Source basis:** which Gobby-source facts it rests on; what is *proposed* vs established.
- **Ripple filter:** how it works with no player present.
- **Sim hook:** the behavioral/mechanical consequence (or "none yet").
- **QC verdict:** pass / pass-with-notes / block.
- **Status:** accepted / revised / superseded.
- **Open question left:** the honest unknown, if any.
```

Keep entries short — this is a craft ledger, not project state (`active_context.md`) and not a lesson
(`reflection_log.md`).
